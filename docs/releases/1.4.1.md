# WuwaTappo 极简版 1.4.1

发布日期：2026-10-29

这是独立的极简版本，只保留两项核心功能：

```text
1. 模拟键盘连点
2. 宝箱就绪时自动打开
```

---

## 功能

### 模拟连点

- 使用 F13–F24 作为模拟输出键，默认 F24。
- 速率 1–50 次/秒，可拖动或直接输入。
- 开始 / 停止：

```text
F8   开始 / 停止
F3   停止
```

### 自动开箱

- 通过 UI Automation 读取两个宝箱的按钮状态。
- 宝箱就绪且累计点击达到 1000 后自动打开。
- 一次只打开一个宝箱。
- 自动开箱默认关闭，按 F11 开关。
- 没有手动开箱按钮。

### 计数防截断

- 小于 100,000 显示完整数字。
- 大于等于 100,000 显示 K。
- 大于等于 1,000,000 显示 M。
- 大于等于 1,000,000,000 显示 B。
- 根据文字长度自动缩小字号。
- 鼠标悬停显示完整数字。
- 窗口加宽到 470×300，避免计数和按钮拥挤。

### 窗口

```text
470 × 300
```

只包含：

- 当前应用点击
- 本次已开箱
- 速率
- 模拟键
- 开始 / 停止
- 自动开箱开关
- 两个宝箱状态
- 底部快捷键提示

没有人物、对话、气泡、桌宠、值守窗口、成就、统计、线索币、设置页和背景图。

---

## 数据

极简版使用独立目录：

```text
%APPDATA%\WuwaTappoMini\config.json
```

只保存速率和模拟键。

- 不读取 1.3 的 `%APPDATA%\WuwaAutoChest`；
- 不写统计，不写成就；
- 不会覆盖 1.3 最终版的数据；
- 1.3 和 1.4 可以同时保留。

---

## 安装

1. 解压 `WuwaTappo极简版_v1.4.1_portable.zip`。
2. 保留 `_internal` 文件夹。
3. 双击 `WuwaTappo 极简版.exe`。
4. UAC 提示选择“是”。
5. 打开 Wuwa Tappo，确认桌宠可见。
6. 按 F8 开始，F3 停止，F11 开关自动开箱。

---

## 已知限制

- 需要管理员权限。
- 自动开箱依赖 Wuwa Tappo 的 UI Automation 控件类名。
- 不读取奖励品质或奖励分类。
- 自动化操作存在账号风险，请自行判断是否使用。
- 本软件不是库洛游戏官方产品。
